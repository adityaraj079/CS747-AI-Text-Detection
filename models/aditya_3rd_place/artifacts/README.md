# Model artifacts

These are the fitted assets for the project-specific low-memory adaptation, not verified original competition weights:

- `bpe_tokenizer.json`
- `tfidf_vectorizer.joblib`
- `sgd_classifier.joblib`
- `catboost_classifier.cbm`
- `configuration.json`

The configuration records the training dataset and split fingerprints, hyperparameters, validation-selected blend weights, and software versions. The source CSVs are not included.
